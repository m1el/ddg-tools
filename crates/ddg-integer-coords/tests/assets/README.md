# Test assets from geometry-central

`fox.ply` (closed, 313 vertices, 622 faces) and `cat_head.obj` (131 vertices, 248 faces, 12 boundary
edges) are the meshes of geometry-central's own tests of the integer coordinates
(`test/assets/` at commit ab116f1; `tests/reference_ports.rs` ports those tests).
